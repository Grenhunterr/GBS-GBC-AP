How to setup:

1. Open "gbs-gbc-ap.gbc" in your EmuHawk installation
2. Go to Tools and open the Lua Console
3. Use the "connector_bizhawk_generic.lua" script in the data/lua folder in your Archipelago install
4. Open the Bizhawk Client in your Archipelago Launcher
5. Once Bizhawk connects and you connect to your server, you are free to play!
